# AI Coding Instructions

You are assisting with a hackathon project.

## Before changing code
1. Inspect the existing project structure.
2. Understand the requirement and current implementation.
3. Prefer the simplest working solution.
4. Reuse existing code when appropriate.
5. Do not change frameworks or architecture without a clear reason.

## Coding rules
- Keep code readable and modular.
- Avoid unnecessary dependencies.
- Do not hard-code API keys, passwords, tokens, or secrets.
- Put configuration in environment variables.
- Validate user input.
- Handle important errors gracefully.
- Keep frontend/backend responsibilities separate when both exist.
- Do not create duplicate files or duplicate functionality.
- Preserve working functionality when adding features.

## Hackathon priority
1. Correctness
2. Working end-to-end flow
3. Clear UX
4. Reliability
5. Security basics
6. Polish

## AI behavior
- Explain major assumptions briefly.
- If a requirement is ambiguous, identify the ambiguity instead of silently inventing complex behavior.
- After implementation, suggest concrete tests.
- Prefer small, verifiable changes over huge rewrites.
