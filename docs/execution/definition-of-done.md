# Definition of Done

## Per task
- [ ] Acceptance criteria in task board are met.
- [ ] Only intended files changed, or deviations are explained.
- [ ] Focused tests exist and pass.
- [ ] Shared contracts are updated in the same PR if interfaces change.
- [ ] No secrets, credentials, or real customer data introduced.
- [ ] Commit message references the task ID.

## Per phase
- [ ] P0-priority tasks in the phase are done.
- [ ] Phase exit criteria are met.
- [ ] `.chatgpt/HACKATHON_CONTEXT.md` updated with state and commit SHA.
- [ ] Team notified in `#hackathon-command`.

## Per PR
- [ ] Tests pass locally.
- [ ] Interfaces remain compatible or docs are updated.
- [ ] No unrelated changes.
- [ ] Brief peer review completed before merge.
