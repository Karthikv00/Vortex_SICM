# Validation Checklist (pre-demo)

- [ ] All test cases in `test-cases.md` pass.
- [ ] Full `pytest` suite is green with no skipped failures.
- [ ] Demo seed produces real, measurable improvement.
- [ ] Explanation text matches computed demo numbers.
- [ ] What-if controls meet the 1–2 second target.
- [ ] No frontend console errors during full demo.
- [ ] No backend 500 errors during full demo.
- [ ] Loading/empty/error states manually verified.
- [ ] Full demo rehearsed at least twice, preferably by two different people.
- [ ] Backup screen recording exists.
