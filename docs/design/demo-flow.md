# Demo Flow

Deterministic, seeded, rehearsed; no dependency on unpredictable external services.

1. Open dashboard in `normal` scenario.
2. Point out current queues and calm baseline waits.
3. Switch to `surge`.
4. Show forecast arrival spike.
5. Show explicit overload alerts.
6. Click **Optimize**.
7. Show recommended allocation and staff movement vs baseline.
8. Show measured before/after wait and overload reduction.
9. Highlight/read the explanation tied to actual numbers.
10. Use what-if to test a manual alternative; show worse or honestly comparable results.
11. Return to optimized allocation as the operational takeaway.

Core steps 1–9 target ~90 seconds; remaining time is what-if and questions.
